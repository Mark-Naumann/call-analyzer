# Instructions for AI assistants working on this repo

- The owner is new to coding. Explain each step in plain, simple words before doing it.
- Keep any API keys or secrets in a `.env` file, never in the repo. Never print a key.
- This repo is documentation and redacted config only. No call recordings, transcripts,
  caller names, phone numbers, emails, org IDs or webhook URLs, ever. Examples describe
  what happened in plain words.
- Config files in `config/` come from the redacted exports in painting-agent and
  transit-agent; re-copy from there instead of exporting by hand.
- The repo stays PRIVATE until the owner has checked it.
